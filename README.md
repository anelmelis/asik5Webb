# Assignment 5 — JavaScript Basics

SE-2527 MELIS ANEL

## Project Description

This project was developed for Assignment 5 of the Front-End Development course. It demonstrates fundamental JavaScript concepts, DOM manipulation, and event handling through nine interactive tasks.

The website includes a navigation bar that allows users to move between separate task pages.

## Technologies Used

- HTML5 — webpage structure
- CSS3 — styling and responsive design
- JavaScript — DOM manipulation, event handling, and interactive functionality
- GitHub Pages — website deployment

## Completed Tasks

| Task | Description |
|---|---|
| Task 0 | First Script — console.log() and alert() |
| Task 1 | Variables & Operators — data types and arithmetic |
| Task 2 | Changing Content — modifying paragraph text |
| Task 3 | Changing Styles — background color and font size |
| Task 4 | Creating & Removing Elements — dynamic list management |
| Task 5 | Mouse Events — mouseover and mouseout |
| Task 6 | Keyboard Events — displaying input using keyup |
| Task 7 | Calculator — four arithmetic operations |
| Task 8 | To-Do List — adding, completing, and deleting tasks |

## Project Structure

The project contains a main `index.html` page, a shared `style.css` file, and separate folders from `task0` to `task8`.

Each task has its own HTML and JavaScript files.

## How to Run

1. Download or clone the GitHub repository.
2. Open the project folder in Visual Studio Code.
3. Open the main `index.html` file using Live Server or a web browser.
4. Use the navigation bar to explore the tasks.

Alternatively, open the published website directly through GitHub Pages.
